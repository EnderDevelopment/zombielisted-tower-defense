# Zombielisted Tower Defense

Zombielisted Tower Defense is a Roblox Tower Defense Simulator that allows players to build and upgrade towers to defend against waves of enemies. The game features a variety of tower types, each with unique abilities, and a dynamic enemy spawning system that increases in difficulty with each wave. Players can strategically place towers to create a robust defense system and survive as long as possible against the onslaught of enemies.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `TowerDefenseSimulator.server.lua` script in the `ServerScriptService`.
5. Place the `TowerDefenseSimulator.client.lua` script in either `StarterPlayerScripts` or `StarterCharacterScripts`.
6. Ensure the `TowerGenerator.server.lua` and `EnemyGenerator.server.lua` scripts are in the same folder or a subfolder of `ServerScriptService`.

## Use

1. Launch the Roblox game in Roblox Studio.
2. Players can click on the game world to place towers.
3. Enemies will spawn periodically and move along a predefined path.
4. Towers will automatically target and attack enemies within their range.
5. Players can upgrade towers and build new ones to improve their defense.
